# Bachelor Thesis – NKDBooks Online Bookstore Platform

NKDBooks is a full-stack web application developed as part of my Bachelor’s thesis. The platform is designed for buying and selling books online, supporting both new and second-hand books, while integrating intelligent features to enhance user experience.



## Features

- Browse and search for books  
- Buy and sell books (C2C and B2C model)  
- User authentication and profiles  
- Wishlist functionality  
- Personalized recommendation system  
- Speech-to-text search (voice input)  
- Advanced filtering and search  


## Project Overview

This project explores the development of an online bookstore platform that addresses limitations of existing solutions, such as the lack of direct user-to-user selling and limited personalization.

The application focuses on:
- Improving accessibility and usability  
- Supporting direct transactions between users  
- Enhancing user engagement through intelligent features  


## Architecture

The application follows a client-server architecture and uses the Model-View-Controller (MVC) design pattern.


## Tech Stack

Frontend:
- React  
- Material UI  

Backend:
- Node.js  
- Express.js  

Database:
- MongoDB  

Other:
- Web Speech API (voice search)


## Recommendation System

The platform includes a recommendation system to improve user experience by suggesting relevant books based on:

- Popularity  
- User preferences  
- Wishlist data  


## Security

Basic security measures implemented:
- User authentication and authorization  
- Data validation  
- Secure API communication  


## Objectives

- Develop a scalable online bookstore platform  
- Enable direct book selling between users  
- Improve accessibility using voice-based search  
- Integrate recommendation systems for personalization
